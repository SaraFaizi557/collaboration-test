# Contributors List 👥

A simple collaborative website where anyone can add their name!

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/collabration-test.git
cd collabration-test
```

### 2. Add Your Name
Open `contributors.json` and add your name to the list:

```json
{
  "contributors": [
    "Alice Johnson",
    "Bob Smith",
    "Carol White",
    "David Brown",
    "YOUR NAME HERE"
  ]
}
```

### 3. Commit Your Changes
```bash
git add contributors.json
git commit -m "Add YourName"
```

### 4. Push to GitHub
```bash
git push origin main
```

### 5. Create a Pull Request
- Go to the repository on GitHub
- Click "Create Pull Request"
- Add a simple message like "Add my name"
- Submit!

## 📖 Rules

- Keep names in alphabetical order (optional but appreciated)
- One name per person
- Please use your actual name or the name you'd like to be credited with

## 🎯 What This Project Is

This is a simple collaborative project designed to:
- Practice git workflow (clone, commit, push, PR)
- Build a community contributors list
- Learn how to contribute to open-source projects

## ✨ View the Website

Open `index.html` in your browser to see the contributors list!
